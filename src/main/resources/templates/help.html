User Guidelines & Help

Welcome to the Web Application Requirements Specification and Analysis App. Below are instructions on how to use its main features.

1. Projects

My Projects: After logging in, you can create new projects or view/edit/remove existing ones. Each project acts as a container for your Use Cases and CRC Cards.

Sharing: You can share your projects with other users by specifying their username. Shared projects appear in a separate section on your dashboard.

2. Use Cases

Managing Use Cases: Inside a project, you can add Use Cases. You can add title, actors, preconditions, main flow, and postconditions.

Actors: You can define actors simply by typing their names (comma-separated) when creating or editing a Use Case. The system will automatically create or link them.

Example Actors: Admin, Employee, Customer

3. CRC Cards

Domain Modeling: You can create CRC (Class-Responsibility-Collaboration) cards to design your domain model. Add Class Name, Responsibilities, and Collaborators, and optionally link CRC cards to relevant Use Cases.

4. UML Diagram Generation

Generate Diagrams: For each project, you can generate UML Class diagrams (based on CRC cards) and Use Case diagrams. Select your preferred tool (PlantUML or Nomnoml) to get the corresponding script.

5. Collaboration & Comments

Commenting: You can discuss requirements by leaving comments on any Use Case or CRC Card within your own or shared projects.

6. Profile

Edit Profile: You can click on the username on the top right corner and then you will be able to Manage your Profile (Change your First Name, Last Name, E-mail and Password)
